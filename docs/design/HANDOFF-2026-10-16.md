## §1 — The game in five lines

*Le Grand Strategos* (LGS) is a real-time-with-pause grand strategy game set in a fictional industrializing world, 1800–1950, with a soft end: the player may keep playing past 1950.
Three nations: Albion (industrial power), Galia (centralized gunpowder state), Norden (martial frontier, rich iron, primitive metallurgy).
Pillar: nations make the same good with production methods of different Tier (Bloomery vs Bessemer Process for Steel), and a unit's Effectiveness = Design Tier × Equipment Tier, so industry decides wars.
Architecture model: Victoria 3. Content and the political capital idea: EU4.
Solo project, about 5 hours a week. Diogo designs in claude.ai and codes through Claude Code.

## §4 — Decisions taken (all confirmed by Diogo)

**Language and process**
- English is the source language for terms, docs, data and game text, in US spelling. Conversation with Claude stays in Portuguese. PT-BR comes later as a translation; the first build ships English only, with all text from keys (`82` §1, §4.15, rule 9).
- Each doc converts to English when it is next edited. Countable terms carry their plural in the termbase (rule 8).
- Route D, "Fusion": LGS's design with LGP's scope discipline (`91`).
- Propose, then confirm; recon before implementation; fail fast, no fallbacks, one source of truth (`90` §1.4).

**Names that shape everything** (`82` has all 222)
- *Tier* = a rung on any ladder (methods, laws, unit designs); *Level* = building size; *Steel Tier* is the pillar's name.
- *Enactment*, *Enacted*, *Failed*, *Chance of Success* (no vote is simulated). *Approval* (Interest Groups) vs *Needs Met* (pops); *Alignment* stays apart.
- IG `IG_Laborers` displays as *Workers*; `IG_Military` as *Armed Forces*.
- *Shortage* and *Surplus* for goods; *Deficit* and *Balance* for money. *Private Investment* replaces "Bourgeoisie auto-investment".
- Effectiveness = *Design Tier* × *Equipment Tier*. Unit types are always qualified; bare "Artillery" is the good.
- Panel F3 is *Economy* (tabs National Market, World Market, Treasury). Map modes: Political, Interest Groups, Steel Tier, Market, Deposits, Population, Military. The rail shows icons only.
- Demonyms *Albionian*, *Galian*, *Nordenian*. Eras: I · Flintlock (1800–1840), II · Steam (1840–1870), III · Telegraph (1870–1890), IV · Wireless (1890–1914), V · Mechanization (1914–1950).
- Shared names, the only exceptions to "one word, one concept": Military, Economy, Religion, Nation, Steel Tier, Market.

**Batch 6 (Oct 16)**
- **Steel ladder** from the goods doc: T1 Bloomery, T2 Puddling, T3 Bessemer Process, T4 Open Hearth, T5 Electric Arc. Crucible is not a Tier. Electricity is deferred, so the first build seeds T1–T4.
- **Market model:** one National Market per nation (the Economy v1 stockpile) and one World Market. The World Market is new design: Economy v1 has no trade (`94` §9.5).
- **Goods:** the 31 of the goods doc; the first build seeds 12: Grain, Iron Ore, Coal, Wood, Fiber, Steel, Fabric, Tools, Small Arms, Artillery, Clothes, Furniture.
- **Currency:** *Crown* / *Crowns*. Money rows: Taxes, Tax Rate, Wages, State Profits, Maintenance, Army Upkeep, Administration, Debt, Interest, Loan, Bankruptcy. Ownership: *State-Owned* / *Private*. Indices: Military Readiness, Industrial Capacity, *Home Front*.
- **Professions and strata:** Lower — Peasant, Laborer, Machinist, Soldier. Middle — Artisan, Clerk, Officer. Upper — Capitalist, Aristocrat. No Clergy profession.
- **Needs:** Life Needs, Everyday Needs, Luxury Needs. **Spheres:** the seven of the code.
- **Collisions C1–C18** resolved in `82` §4.18–4.31 (Capital = capital province; *Political Capital Cap*; Morale is units only; Supply is the market's; Throughput is a dev term).
- The goods doc is numbered `34` (it was written as `41-goods-and-chains`, which collided with population).

## §10 — Lessons from this arc

- **Check the code before trusting a doc.** Docs said the modifier registry existed and that the Military law ladder absorbed an existing mechanic; the code had neither (`94` §5, `95` M1).
- **Memory and chat summaries go stale.** Old summaries still describe LGS as an Unreal project. Read `00` first; it is dated.
- **Reports are snapshots.** Decisions taken on a report go to the doc that owns them (`00` §11).
- **One editor per canvas.** Two sessions converted the same canvas in parallel and one had to merge (`83`).
- **Several sessions work in parallel.** Before acting on the state, search recent chats for newer work on the same docs.
- **A rule that looks like a fallback may be a game rule.** The automatic loan is Victoria 3's design, not hidden error handling (`94` §8).
- **Names first, code second.** Every new player-visible word gets a `82` row before it reaches a screen or a data file.

```markdown
# CLAUDE.md — Le Grand Strategos

Read this first in every session. Then read `docs/00-start-here.md` for the current state.

## The project
Grand strategy, real-time with pause, fictional industrializing world, 1800–1950 with a soft end.
Nations: Albion, Galia, Norden. Pillar: the same good made by production methods of different Tier;
unit Effectiveness = Design Tier × Equipment Tier. Model: Victoria 3. Solo developer, ~5 h/week.

## Stack
- Godot 4.7.x stable (do not chase dev builds), C#, .NET 8.
- `src/Strategos.Sim`: pure C# simulation. **Never references Godot** (ADR-0001, `docs/92`); a test enforces it.
- `src/Strategos.Game`: Godot project; presentation and input only.
- `tests/`: xUnit. `data/`: JSON content (ADR-0002). `tools/`: CLIs (FMG import, termbase generator).

## Language
- English for docs, comments, data and game text, US spelling. Conversation with Diogo in Portuguese.
- Every player-visible string comes from a key in `data/loc/` (`docs/82`). No literal UI strings.
- Use the names in `docs/82` exactly. Never a retired variant; the retired-variant check fails the build.

## Principles
1. One source of truth: no parallel grammars of rules.
2. Fail fast: throw on a broken precondition. No fallbacks, no silent defaults, no "skip if missing".
3. Systems consume other systems; they do not grow parallel engines.
4. `Tier` is its own type and only names rungs of a ladder.
5. No fabricated identifiers: an id that is not verified against code or data is marked `⚠ RECONCILIAR`.
6. Derive parameters from systems instead of choosing them arbitrarily.
7. Recon before implementation: audit, write a report in `docs/`, wait for approval, then implement.
Also: simple beats complex; one way to do things; clarity over compatibility; surgical changes;
separation of concerns; fix root causes.

## Simulation conventions
- `SimId` is the only key type. Never a raw string or a list index as identity.
- `DeterministicRng` is the only randomness; its state is serializable.
- Iterate in explicit `SimId` order. Never depend on dictionary or hash-set order.
- Tuning numbers live in `data/`, not in code.
- The loader validates every reference and throws with file, line and id.

## Workflow
- Two turns for any non-trivial change: plan or recon first, implementation after Diogo approves.
- Conventional Commits, one per logical step. Never `--amend`, never `--no-verify`.
- Do not push or merge without Diogo's explicit authorization.
- After each step: `dotnet build` and `dotnet test`; paste the summary. If a "done when" fails, stop and report.

## Docs
- `docs/00-start-here.md` (state), `docs/93` (sprint), `docs/82` (names), `docs/92` (ADR-0001).
- Status markers: [DECIDED], LOCKED vX, [PROPOSED], [OPEN], [REF], ⚠ RECONCILIAR.
- Reports (`94`, `95`, `96`) are dated snapshots: never edit them; record decisions in the doc that owns them.

## Known traps from the Unreal Economy v1 (docs/94)
- There is no modifier registry to port; it is new work.
- Money is not conserved in v1; port it as it is unless `docs/94` §10 says otherwise.
- v1 shares scarce goods first-come by container order; follow the decision in `docs/94` §10.4.
```
